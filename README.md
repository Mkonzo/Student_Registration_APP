# Student Registration App

## Overview

The **Student Registration App** is an Android mobile application developed using Kotlin and Android Studio. It is designed to simplify the student registration process by allowing users to enter, manage, and store student information digitally.

The project demonstrates Android application development, user interface design, form handling, and database integration.

## Features

- Student registration form.
- Collection of student personal and academic details.
- Course and school selection.
- Input validation to ensure accurate information.
- Database integration for storing student records.
- User-friendly interface.
- Reset functionality to clear registration fields.

## Technologies Used

- **Kotlin** – Main programming language.
- **Android Studio** – Development environment.
- **XML** – User interface design.
- **SQLite / Database** – Local data storage (where implemented).

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Mkonzo/Student_Registration_APP.git
   ```

2. Open Android Studio.

3. Select **Open** and choose the cloned project folder.

4. Allow Gradle to synchronize.

5. Connect an Android device or start an emulator.

6. Click **Run** to launch the application.
